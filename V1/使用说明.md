# 仿生眼数据集检查与纠正 V1

中文 PyQt5 桌面程序，用于已有 **YOLO 目标检测** 数据集的人工检查和修改。编辑后仍保存为 YOLO txt，可继续用于训练。不支持分割多边形、姿态关键点或旋转框标签；这些格式会报错，不能直接当作检测框读取。

## 启动

当前环境已具备运行依赖，在图形桌面终端执行：

```bash
cd '/mnt/ccl/ultralytics/仿生眼数据集标注平台/数据集检查/V1'
./启动数据集检查.sh
```

默认打开同级工业电机数据集中的 `em3_base_model_dataset_head`。也可以通过工具栏“打开数据集”切换，或指定目录 / YAML：

```bash
./启动数据集检查.sh --dataset '/你的数据集目录'
python3 app.py --dataset '/你的数据集目录/data.yaml'
```

如果使用其他 Python 环境：

```bash
python3 -m pip install -r requirements.txt
DATASET_EDITOR_PYTHON='/你的环境/bin/python' ./启动数据集检查.sh
```

需要有图形桌面或图形转发，普通无显示的 SSH 会话不能展示桌面窗口。Windows 安装 Python 3.10 或以上及 requirements.txt 后，可使用 `启动数据集检查.bat`；Windows 平台未在本机实测。

## 支持的目录

标准 YOLO 目录（优先推荐）：

```text
数据集/
  data.yaml
  images/
    train/*.jpg
    val/*.jpg
    test/*.jpg
  labels/
    train/*.txt
    val/*.txt
    test/*.txt
```

也支持 `images/*.jpg + labels/*.txt`，以及图片、同名 txt、`classes.txt` 全在同一目录的标注文件夹。支持 jpg/jpeg/png/bmp/webp/tif/tiff。各层级必须保持图片和标签的相对路径对应。打开整个数据集根目录即可一起检查 train/val/test；左侧搜索 `train/`、`val/`、`test/` 可筛选相应子集。

类别按 `data.yaml` 的 `names` 加载，也兼容 `dataset.yaml`、`data.yml` 和 `classes.txt`。缺少类别配置时，会要求按原有编号顺序填写类别名。不能只凭框形状自动推断名称。

YOLO YAML 中任意外部图片清单、多个分散目录组成的 train 列表目前不作为图片索引读取；请使用上述目录结构。选择文件夹中存在 `images` 时，使用所选目录中的实际图片，避免旧 YAML 的 `path` 指向另一个数据集。

## 检查与修改

1. 左侧点击图片，中间显示图片及彩色标注框，右侧列出框和类别。编号颜色在同一数据集中保持一致。
2. 左键点击框选中它，拖动框内部可改变位置。重叠框默认选择面积较小者；也可以通过右侧列表准确选择。
3. 拖动选中框的八个控制点可调整大小。或在右侧输入左上角 X/Y、宽 W、高 H（像素），点击“应用像素坐标”。坐标基于原图，不受显示缩放影响。
4. 按 `W` 进入绘框模式，在图片上按住左键拖出新框。新框使用类别下拉框当前值。按 `Esc` 退出绘框模式。
5. 选中框后按 `Delete` 删除；重复绘框 / 删除即可改变目标数量。
6. 修改右侧类别下拉框，将**选中的框**改为其他类别。点空白处取消选择后，设置下拉框只改变新框默认类别。
7. 点击“类别管理”可重命名已有类别或追加新类别。修改会立即写入整个数据集的 `data.yaml` 和 `classes.txt`，不重排现有编号，不批量交换 txt 中的类别编号。修改框的类别后仍需保存当前标签。
8. 按 `Ctrl+S` 保存当前图片的标签。`A` / `D` 切换上一张 / 下一张；有未保存修改时会询问保存、放弃或取消。勾选左下角“切图时自动保存修改”后，切图或关闭时自动保存。

默认 head 数据集类别为 `0 = motor_rotor`、`1 = long_motor`。打开和浏览不会改变原标注，只有主动保存标签或类别管理才会写入数据。

| 操作 | 快捷键 / 鼠标 |
|---|---|
| 打开数据集 | Ctrl+O |
| 保存当前标签 | Ctrl+S |
| 上一张 / 下一张可见图片 | A / D |
| 绘制新框 | W |
| 返回选择模式 | Esc |
| 删除选中的框 | Delete |
| 撤销 / 重做当前图片编辑 | Ctrl+Z / Ctrl+Shift+Z |
| 图片适应窗口 | F |
| 缩放图片 | 鼠标滚轮，围绕鼠标位置缩放 |
| 平移图片 | 中键或右键按住拖动 |

撤销记录限当前图片的最近 150 个状态。全局类别名称修改不属于单张图片的撤销历史。

## 标签检查和异常处理

打开数据集时自动检查所有标签，也可以点击“检查数据集”重新扫描。检查包括五列检测格式、整数类别编号、类别是否存在、有限坐标、正宽高和框边界。容许六位小数导出产生的不超过 0.000001 的边界舍入误差。

左侧筛选：有标注、空标签、缺失标签、格式异常、图片异常、未检查。右侧显示异常的文件及行号。“导出检查报告”生成 CSV，方便集中查看。

- **空标签**：已有空 txt，通常表示背景图片。
- **缺失标签**：没有对应 txt，不自动当作背景；保存后才创建标签。
- **格式异常**：禁止直接覆盖，避免把未读出的框丢弃。先查看报错；可以从外部修好后“重新读取当前图片与标签”，也可以新增缺失的类别再重新读取。
- **重建异常标签**：明确确认后，从零个框开始重新画；保存时先备份异常原文件再覆盖。重建之前请确认原文件不是分割等其他任务格式。
- **图片异常**：图片无法解码，禁用标注保存。图片是在打开时解码检查的；全量“检查数据集”扫描的是标签，不代表全部图片已经通过图像解码验证。

## 保存与恢复

YOLO 标签保存为 `class_id x_center y_center width height`，坐标归一化到 0–1，保留八位小数。删除全部框后保存会生成空 txt。

每次覆盖已有标签或类别配置前，自动将原文件备份到：

```text
数据集/.annotation_backups/时间戳/原相对路径
```

保存使用同目录临时文件和原子替换。若标签在打开后被其他程序改动，会拒绝覆盖并提示重新读取。“重新读取当前图片与标签”可在确认放弃本地修改后加载最新磁盘内容。

需要恢复时，关闭编辑器，在备份目录中找到对应文件，复制回原位置。类别重命名的恢复应同时恢复对应版本的 `data.yaml` 和 `classes.txt`。历史备份目录不会作为数据集图片扫描。

程序不刷新 Ultralytics 已存在的 `labels/*.cache`；继续训练时由训练端检查标签缓存，必要时删除旧 `.cache` 以重新扫描。首次使用本程序时不会创建或更改训练标签缓存。

## 文件与验证

- `app.py`：主窗口、浏览筛选、类别管理、保存与快捷键。
- `canvas.py`：图像显示、框绘制 / 拖动 / 缩放、鼠标缩放和平移。
- `dataset.py`：标签格式校验、路径映射、备份与原子保存。
- `test_editor.py`：在临时数据集上验证读写、备份、冲突处理、类别管理及鼠标编辑流程。
- `界面预览.png`：使用真实 head 数据集生成的界面预览。

运行测试：

```bash
QT_QPA_PLATFORM=offscreen python3 test_editor.py
```

测试仅修改临时数据。已在当前 Linux 环境通过；真实 head 数据集只读扫描结果为 6175 张图片、6170 个非空标签、5 个空标签，未发现标签格式异常。
